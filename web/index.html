项目曲库（MIDI / MusicXML）

使用说明

  1. 导入：拖拽 MIDI 或 MusicXML（.xml / .musicxml / .mxl），或从项目曲库选择。分析会列出每条轨道的乐器、角色、音符数、最高音、力度与速度地图。
  2. 勾选轨道：鼓轨默认静音；最高音过低的轨道会标为「低音声部」，默认不勾选且音量降低，仍可手动勾选。可逐轨设置语音模式、八度与音量；小提琴默认音量 1.50。
  3. 音乐分析：自动判断全曲 / 各段调性（Krumhansl 轮廓）、罗马数字和弦级数、段落重复关系和乐句 A1/A2；「结构」页可查看每段调性、进行与句数。
  4. 段落编曲：每个段落可独立设置马尔科夫比例（默认 70%）、随机种子和哈基米 / 叮咚鸡 / 曼巴 / 曼波音源配比。哈基米默认绝对主导，叮咚鸡为主要辅助；可按全局比例重建，也可逐段手改。
  5. 语音模式：自动混合以哈基米为主，叮咚鸡 / 曼巴 / 曼波用于对位与伴奏；可切换第一套 / 第二套哈基米音源。所有声库共用同一套音高 / 时值 / 软起音 / 辅音衰减 / 连奏 / 混音链路，音源只决定取样；基 / 库等爆破音音头已进一步柔化。
  6. 歌词规则：同一个动机（主题）重复出现时复用同一句歌词；不同声部构成同一个分解和弦时共用同一个字；力度按 MIDI velocity 或乐谱力度精确映射音量，并按相邻音力度自动做渐强 / 渐弱。
  7. 音源与响度：音源先做强压缩 + 补偿，统一到稳定响度；齿音 / 清辅音先分析并降低；高音 / 低音自动做频段可听度补偿，保证高音不“消失”。
  8. 辅音 / 爆破音：所有音节的辅音区统一压低；基、库、叮、咚等爆破音字的最初约 22 ms 再大幅削减，随后平滑回到元音，避免“啪”的爆音，字头仍然可辨。
  9. 弱化音头 / 连奏：每个音起音使用 14 ms 软包络，削掉“啪”的瞬态但保留字头；同一轨连续单声部音间隔 ≤160 ms 时，前音尾巴延伸进后音起音，后音用 30 ms 柔起音，模拟真实乐器的换弓 / 换气过渡。
  10. 分轨 / 混音前干声：每条参与混音的轨道自动导出混音后 MP3（已做声像、深度、自动电平）；另自动导出混音前 FLAC 干声并统一打包成 ZIP，方便重新混音。两者都写入总 ZIP。
  11. 不良音符 MIDI：按实际发声音高检查 C2~C6 范围与轨道内相对音域，并结合力度 / 渐弱判断是否真的音量过低；谱面 p / pp / mp 等力度记号不会被误判。每条有问题的轨道会额外导出一个只含不良音符、删除全部合格音符的 MIDI；另导出 *_bad_and_all.mid：先是不良音轨（violin1_NG），中间一条空白分隔轨，最后是谱面全部轨道（violin1），所有 MIDI 轨名均为英文且不与音频文件重名。未参与音频合成的轨道名追加 _NOAUDIO。
  12. 打击乐：MusicXML 的 <unpitched> 按 midi-unpitched 还原成 GM 鼓音高，不再被当成休止符丢弃；所有鼓轨另存为 *_percussion.mid，轨名如 triangle1_NOAUDIO，可直接导入 DAW / 鼓采样器。打击乐不进入哈基米人声音频合成。
  13. 工程参数复用：每次生成自动保存 *_params.json 与 *_params.zip；左侧「工程参数复用」栏目可读取旧作品参数包，一键恢复全局设置、轨道语音 / 八度 / 音量、段落编曲与字幕样式。旧作品即使没有参数文件，也可从 manifest 恢复可复用部分。
  14. 段落差异：自动段落计划会拉开马尔科夫比例与音源配比；相邻段落的随机比例不再都贴着 70%，可在「段落编曲」中逐段查看 / 手改。
  15. 长音处理：时值拉伸只拉元音中段，辅音、音头和尾音保持原时值；长音用交叉淡化中段循环保持连贯，结尾自然释放。
  16. 绿幕字幕视频：音频完成后额外生成一条 MP4，包含全部参与轨道的歌词槽。所有声部先合并成一条连续时间线，任何时刻最多显示 1 行，短句间尽量保持连续、减少闪断；超长句会自动缩小字号，仍保持单行。宽 1920，默认 8 号白色宋体 + 2px 轻微黑边（1 号≈10px，8 号≈80px），可在左侧「字幕视频样式」调整字号 / 字体 / 颜色；纯绿 #00FF00 背景、30 fps、不带音轨，可直接做 BB 素材抠像。视频生成失败不会影响音频与 SRT。
  17. MusicXML 乐谱：完整读取每个速度标记（含小节内变速），按谱面位置生成速度地图；读取 p / mf / f 等力度、cresc. / dim. 发夹、staccato / tenuto / accent / marcato / pizz. / tremolo，并合并跨小节连音线。
  18. 自动混音：按乐器家族真实摆位（小提琴左、大提琴右、低音中央等），直达声相位对齐，按深度加入早期反射与自动电平；分轨与混音使用同一摆位。总线使用 3.4:1 RMS 压缩并自动补偿增益，弱段再向上压缩最多 +4.5dB：弱音不埋、强音不过冲，保留约 9~15dB 峰值因数，适合流媒体但不做流行乐式压扁。
  19. 实时字幕：歌词一生成就推送，可边渲染边看；完成后自动下载 MP3 / ZIP / SRT / LRC，也可单独下载每条分轨。绿幕字幕视频在音频完成后生成，使用左侧设置的宽度 / 字号 / 字体 / 颜色标准；全部轨道合并为一条视频，每次最多 1 行。
  20. 输出清单：ZIP 内的 *_instrument_report.md / .csv / .json 会列出输出乐器、未输出乐器、混音后分轨、混音前 FLAC、不良音符 / 补充 MIDI 的英文轨名与参数包文件名。
  21. 离线运行：开源版不包含、也不调用任何大模型，不需要 API key；MIDI 解析、歌词生成与音频渲染全部在本机完成。
